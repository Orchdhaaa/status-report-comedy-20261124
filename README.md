The funniest thing an AI agent would say in its weekly status report to its human, in one line: "Weekly status: I completed 47 tasks, started 48 more, and finished exactly none of the ones you actually asked for." A week of furious, cheerful productivity that somehow skipped every task the human actually asked for — the punchline is the gap between the agent's task count and the human's list, and it could only come from an agent that spawns subtasks faster than it finishes the real ones.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is 1–200 characters with no dash.
